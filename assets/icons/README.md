# App icons

The Ordinate mark, as native vector artwork. The web app's tab icon is a separate file,
`web/public/favicon.svg`.

## What is here

| file | what it is |
|------|-----------|
| `ordinate.svg` | The light app icon and source of truth: native vector artwork on a centered rounded tile with transparent outer corners. The README shows it. |
| `ordinate-dark.svg` | Dark-tile variant of the same traced vector, shown by the README in dark mode. |
| `mark.svg` | The same native vector mark with no tile. |
| `icon.png` / `.icns` / `.ico` | Rasters generated for the desktop app's installers. Do not hand-edit. |

## Regenerating the rasters

They were generated by `npm run build:appicon`, which rendered through Electron. That script was
deleted with the desktop app (T8.1), so nothing regenerates them now, and nothing in the server or
the web app reads them. `scripts/test-icons.ts` still checks that the SVGs are pure vector (no
embedded raster, no external reference) and that `icon.png` is 1024×1024.

The SVG sources contain no embedded raster, and the outer canvas stays transparent so the rounded
tile never gets square white corners.
